# Scratchpay

> Scratchpay (Scratch Financial, Inc., NMLS ID 1582666) is a digital payment and financing platform for veterinary and human healthcare. Practices offer borrowers Scratch Pay installment plans ($200–$10,000, 12–24 months) and Scratch Checkout payment processing; the partner/borrower API lets integrators submit loan applications and receive an asynchronous approve/decline decision via callback.

## APIs
- [Scratchpay-API (borrower application)](https://github.com/scratchpay/Scratchpay-API): POST /application — submit a borrower loan application, returns a phone-verification redirect URL.
- [Scratchpay Care Credit API](https://github.com/scratchpay/Scratchpay-API): POST /application — application flow keyed by practice URL.
- [Partner-API (result callback)](https://github.com/scratchpay/Scratchpay-API): POST /application/{loanUniqueId}/result — Scratchpay delivers the decision to the partner.
